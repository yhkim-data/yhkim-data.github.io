Process

02
01

Diagnose

보유 데이터와 과제 목표를 검토하고 분석 가능성을 진단합니다.

받는 것
  • 분석 가능성 진단 결과
  • 적합한 서비스와 예상 일정 안내
02

Design

방법론과 추진 체계, 산출물 기준을 설계합니다.

받는 것
  • 방법론·추진 체계 제안
  • 산출물 기준과 과업 범위 확정
03

Model

통계 분석과 모델링을 수행해 결과를 도출합니다.

받는 것
  • 분석·모델링 결과
  • 재현 가능한 코드와 문서
04

Deliver

결과를 검증하고 보고서와 데이터셋으로 전달합니다.

받는 것
  • 검증을 마친 최종 산출물
  • 서비스별 산출물(보고서·데이터셋·코드 등)
